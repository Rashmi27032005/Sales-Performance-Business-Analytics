\# Sales Performance \& Business Analytics



\## Project Overview

An end-to-end data analytics project developed as part of the InternNova Data Analytics Internship.



\## Objective

To analyze sales data, identify important business trends and patterns, create meaningful visualizations, and develop an interactive Power BI dashboard for data-driven decision making.



\## Tools Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- SQL

\- Excel

\- Power BI

\- Git \& GitHub

Project development in progress.
